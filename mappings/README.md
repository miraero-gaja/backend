# Semantic mappings

G2-A implements conservative metadata registries only:

- [`concepts/`](concepts/README.md) retains official schema display names as
  review candidates; it does not confirm or unify financial concepts.
- [`coverage/`](coverage/README.md) maps every occurrence-aware source column to
  its typed, concept, unit, code, identifier, and supported-operation status.

The `aliases/` and `units/` areas are still placeholders. No canonical concept,
alias, unit, currency, percentage meaning, or ontology term is inferred from
source values.
